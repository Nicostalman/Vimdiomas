# M2 · Pinyin — Plan

## 1. Dependency setup

- Add `pypinyin` to `[project]` `dependencies` in `pyproject.toml`.
- Reinstall (`pip install -e ".[dev]"`) and confirm `import pypinyin` works.

## 2. Syllable tone-mark tables

- Build the tone-mark placement table: which vowel in a syllable takes the mark, per the standard pinyin rule (`a`/`e` always win; `ou` marks `o`; otherwise the last vowel in the group, e.g. `iu` marks `u`, `ui` marks `i`).
- Build the tone-number ↔ diacritic map for each vowel (1=macron, 2=acute, 3=caron, 4=grave, 5/0=none) for `a e i o u ü`.

## 3. `to_tone_marks`

- Syllable splitter: walk a numbered-pinyin string and split it into `(letters, tone_digit)` syllables. A syllable boundary is a digit (1-5, or 0) followed by the next letter run.
- Normalize `v` and `u:` to `ü` internally before applying the tone mark.
- Apply the tone-mark table to place the diacritic on the correct vowel; tone 5/0 leaves the syllable unmarked (bare letters, `ü` rendered as `ü`).
- Rejoin syllables into the output string.

## 4. `from_tone_marks`

- Syllable splitter for tone-marked input: split on vowel-with-diacritic boundaries (a marked vowel signals "one tone value found here"; syllable boundaries otherwise follow standard pinyin syllable structure — reuse/adjacent to the initial+final tables from step 2 if needed, or split on a simpler heuristic since input is machine-generated by `to_tone_marks`/hand-typed transcription).
- For each syllable, detect the diacritic (if any) to recover the tone digit (5 if none found), and strip it back to the bare vowel.
- Map `ü` back to canonical `u:` in the numbered output.
- Rejoin into `letters+digit` syllables, concatenated (matching `to_tone_marks`'s input shape).

## 5. `guess`

- Call `pypinyin.pinyin(hanzi, style=pypinyin.Style.TONE3, neutral_tone_with_five=True)` (or equivalent), flatten the result, and join into a single numbered-pinyin string with no separators, matching `guess("牛肉") -> "niu2rou4"`.

## 6. Conversion table fixture + tests

- Write a fixture (e.g. `tests/fixtures/pinyin_table.py` or a data file) of ~40 `(numbered, marked)` pairs covering: all four tones, neutral (5 and 0 input forms), `ü` via both `v` and `u:`, `ou`, `iu`, `ui`, and at least a few multi-syllable words.
- Test `to_tone_marks(numbered) == marked` and `from_tone_marks(marked) == <canonical numbered form>` for every row.
- Add a couple of direct `guess()` tests against known hanzi (e.g. `牛肉`, `你好`) asserting the numbered-pinyin output, without over-testing `pypinyin` itself.
